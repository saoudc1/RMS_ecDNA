# MSK-IMPACT RMS ecDNA analysis

This repository contains the R script used to reproduce the MSK-IMPACT rhabdomyosarcoma analyses described in Saoud et al.

## Contents

- `MSK_IMPACT_RMS_analysis.R` — analysis script.


## R packages

The analysis uses the following R packages:

- dplyr
- tidyr
- stringr
- purrr
- tibble
- ggplot2
- scales
- ComplexHeatmap
- survival
- survminer
- coxphf
- grid
- gridExtra
- cowplot
