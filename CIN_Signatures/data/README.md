# Data

Place the analysis inputs in this directory.

```text
data/
├── ASCAT_segments/
├── Joined_final.csv
└── WGS_RMS_noMRN.csv
```

`ASCAT_segments/` may contain nested directories. The analysis searches recursively for files ending in `_tumor.segments_raw.txt`.

Data files are not included in this repository and should be distributed separately according to the applicable data-access and consent requirements.
